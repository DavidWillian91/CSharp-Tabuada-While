# 📚 Exercício - Tabuada com While em C#

Projeto desenvolvido durante meus estudos de C# com o objetivo de praticar estruturas de repetição utilizando o comando `while`.

## 🎯 Objetivo

Criar um programa que:

- Receba um número informado pelo usuário;
- Verifique se o número é maior que zero;
- Gere a tabuada do número de 1 a 10;
- Utilize a estrutura de repetição `while`;
- Exiba uma mensagem caso o número informado seja inválido.

## 🛠️ Tecnologias utilizadas

- C#
- .NET
- Console Application

## 📌 Conceitos praticados

- Variáveis
- Entrada de dados com `Console.ReadLine()`
- Conversão de dados com `Convert.ToInt32()`
- Estrutura condicional `if/else`
- Estrutura de repetição `while`
- Operadores matemáticos
- Interpolação de strings

## 💻 Exemplo

Ao informar o número `5`, o programa apresenta:

5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
...
5 x 10 = 50

## 📈 Objetivo de aprendizado

Este projeto faz parte da minha jornada de aprendizado em C#, servindo como prática dos fundamentos da linguagem e preparação para projetos maiores utilizando .NET.
